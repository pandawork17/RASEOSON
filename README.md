## RASEOSON
RASEOSON 홈쇼핑 본사/지사/구매자 홈페이지 관리

#3조 git 규칙
1. 각자 자기 branch에서만 작업한다.

2. 작업한 내용은 자기 branch에 commit + push한다.

3. main에서는 직접 개발하지 않는다.

4. main은 최종 통합본으로만 사용한다.

5. park와 song의 작업은 an이 확인한 후 main에 merge한다.

6. an의 작업도 먼저 an branch에 올린 후, 최종적으로 main에 merge한다.

7. 다른 컴퓨터에서 작업할 때는 같은 자기 branch를 pull해서 이어서 작업한다.
